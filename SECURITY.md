# Security

Found a security problem in Lymow Remote? Please **do not open a public issue**. Report it privately through
GitHub's [private vulnerability reporting](https://github.com/AppGuy77/lymow-remote-downloads/security/advisories/new),
with the version and the steps to reproduce. You will get an answer, and a fixed release when it is confirmed.

Lymow Remote is independent of Lymow; problems with the mower, its firmware or the Lymow cloud belong with Lymow.
