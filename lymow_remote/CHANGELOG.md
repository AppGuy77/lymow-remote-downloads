Lymow Remote v1.0.1

The first release of Lymow Remote: the remote control of the Lymow Toolkit on its own, for Lymow One and One Plus mowers.


- **Drive with a live camera, always full screen** — two joysticks on a phone, one with a mouse, blades, deck height and the light.
- **Only the essentials:** Pause/Resume, Clear Fault, Cancel Task and Dock. Starting a mow stays with the Lymow Toolkit and the official app.
- **At home and away:** scan the QR code in ⚙ at home, or use your permanent away-from-home address from anywhere.
- **WiFi when it can work, 4G when it cannot** — it checks the mower's own network before every camera start and says why.
- **A disclaimer to accept each time it opens**, before the camera or remote control can be used.

## Install

- **Windows:** `LymowRemoteSetup-v1.0.1.msi`
- **Ubuntu / Linux:** `lymow-remote-ubuntu-v1.0.1.tar.gz`
- **macOS:** `lymow-remote-mac-v1.0.1.tar.gz`
- **Docker:** `lymow-remote-docker-v1.0.1.tar.gz`, or the image `ghcr.io/appguy77/lymow-remote:1.0.1` (also `appguy77/lymow-remote` on Docker Hub)
- **Home Assistant:** add `https://github.com/AppGuy77/lymow-remote-downloads` to the Add-on Store's repositories, then install **Lymow Remote**.

Lymow Remote installs next to the Lymow Toolkit on the same computer without clashing (its own ports 8790/8791 and service).
It uses one cloud connection per Lymow account, like the official app: while you drive, other apps on the account are paused.

**On an iPhone**, add Lymow Remote to your Home Screen first — the camera screen shows the steps.
